# BackEnd E-Rent

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## Deskripsi
BackEnd E-Rent adalah sistem *backend* dan API untuk aplikasi platform penyewaan elektronik (e-rent). Proyek ini dirancang untuk menyediakan fondasi pengelolaan data inventaris sewaan, autentikasi pengguna, dan pencatatan transaksi yang efisien. 

*Catatan: Proyek ini sedang dalam fase modernisasi untuk memperbarui basis kode lama menjadi standar arsitektur dan keamanan backend yang lebih baru.*

## Fitur Utama
* **API Manajemen Inventaris**: Endpoint untuk menambah, mengedit, dan menghapus barang sewaan.
* **Sistem Autentikasi**: Mengamankan akses ke *dashboard* dan endpoint API.
* **Manajemen Transaksi**: Pemrosesan dan pencatatan riwayat sewa.

## Struktur Direktori
* `/api` - Endpoint API untuk dikonsumsi oleh *frontend* atau aplikasi *mobile*.
* `/application` - Logika inti *backend* (Controllers, Models, Views).
* `/system` - Core files *framework*.
* `/assets` - Aset statis seperti CSS, JS, dan gambar pendukung.
